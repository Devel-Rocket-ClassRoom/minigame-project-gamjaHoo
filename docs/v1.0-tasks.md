# V1.0 Tasks

V1.0 구현 작업 단위 분할. 의존성 순서대로 정렬되어 있으며, 위에서부터 차례로 작업한다.

각 작업은 **검증 가능한 완료 조건**을 가진다.

> **선행 문서:**
> - `docs/v1.0-plan.md` (광범위 명세 + Q1~Q12 결정)
> - `docs/design-decisions.md` #58~#65 (V1.0 결정사항)
> - `docs/algorithms.md` Part 3 V1.0-1 ~ V1.0-10 (V1.0 알고리즘 명세)
> - `docs/unity-mcp-setup.md` (Stage 0 상세)
> - `docs/unity-ai/muip-reference.md` (V1.0 보강본)
>
> **일정 (Q11 확정):** 마감 없음 — Stage 단위 GitHub Issue 일괄 생성 후 진행도는 보드 (#50) 추적.
>
> **Sub-PR 패턴 (V0.5 그대로):** Sub-A 명세 갱신 → Sub-B 구현 → Sub-C asset chore.
>
> **Save Migration**: V0.5 → V1.0 무효 (Q-MIG 합의). V1.0 신규 게임만. saveVersion = 3.
