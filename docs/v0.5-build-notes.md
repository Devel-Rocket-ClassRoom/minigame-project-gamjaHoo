# FM-Lite V0.5 빌드 노트

> **빌드 일자:** 2026-05-29
> **컨셉:** FM의 육성 부분만 떼어내서 시간 압축한 컴팩트 매니저 게임 — 한 시즌 2~3시간 완주.
> **목적:** V0.1 의 "한 시즌 완주" 위에 "한 시즌이 *재미있게* 진행" 달성 — 매치 시뮬 + 사기 + 트레잇 + 시설 효과 + 시즌 시상.
> **선행 빌드:** V0.1 (2026-05-22) — `docs/v0.1-build-notes.md`.

---

## 1. 구현된 기능

### 1.1 게임 진행 루프 (V0.1 그대로 + 시즌 종료 확장)
- 메인 메뉴 → New Game (시드 입력 / 자동) 또는 Load Game (슬롯 리스트)
- 구단 선택 (명성 내림차순)
- 스타팅 스쿼드 가챠 (4라인 5단계 티어 + ACE 마커, 리롤 최대 3회)
- Dashboard (날짜 / 다음 경기 / 리롤 토큰 / **인박스** / **사기·부상 요약** / **다음 매치 상세**) — [Continue] 로 다음 정지 이벤트까지 자동 진행
- 시즌 종료 (5/15) → **SeasonSummaryScene** (시상 / 보드 평가 / 재정 결산 / 다음 시즌 목표) → 회계연도 (6/1) → 새 시즌 매치 개막 (8/15) 자동 사이클

### 1.2 도메인 시스템 (Stage A~M 결과)

| 시스템 | V0.5 동작 |
| --- | --- |
| **PlayerGenerator** | **49 stats × 1-100** (FM26 1:1 매핑 — Tech 14 / Mental 14 / Phys 8 / GK 13) + **Hidden Attributes 9종** (loyalty / ambition / professionalism / pressureHandling / temperament / controversy / injuryProneness / consistency / versatility) |
| **TraitSO** | 6 → **20 트레잇** 카탈로그 + `effects: List<TraitEffect>` 5종 (MatchModifier / GrowthRateModifier / InjuryRateModifier / MoralePropensity / MarketValueModifier) + 충돌 그룹 3개 |
| **ClubGenerator** | 4티어 명성 + **포메이션 가챠 랜덤화** (Solid / Balanced / Flamboyant — 명성 비례 가중) + 자동 캡틴/부캡틴 배정 |
| **ScheduleGenerator** | Berger 더블 라운드 로빈 (V0.1 동일) |
| **MatchSimulator** | **5-Zone Markov** 매치 엔진 (HomeBox/HomeDefense/Midfield/AwayDefense/AwayBox + possession 상태 머신) + 49 stat zone별 매핑 + 부상/카드/페널티/연장/승부차기 + 평점 + **텍스트 이벤트** (collectEvents 옵션) |
| **MatchPostProcessor** | 결과 기록 + 시즌 통계 (yellowCards/redCards/minutesPlayed/saves) + 라인 순위 갱신 + Suspension 누적 + **MoraleSystem.OnMatchFinished** 호출 |
| **BackgroundSimulator** | **동일 5-zone Markov 엔진** + `collectEvents=false` (텍스트 로그만 생략, 통계 수집) |
| **YouthSystem** | 메인 6/15 + 보조 1/15 인스펙션 + **유스 CA 캡 30-95** + 라운드별 포지션 가중치 + 미영입 후보 **AI 다른 구단 영입 (30% 확률)** + **1군 콜업 자동 트리거** (18세 + CA ≥ 클럽 평균 ×0.70) |
| **TransferSystem** | Market Value 6요소 + **CounterOffer 4분기 응답** (Accept / CounterOffer / Rejected / Mocking) + **선수 협상 (Negotiating)** + **임대 시스템** (loanFee / loanEndDate / 자동 복귀) + **상시 재계약** + **FA 시장** (잔여 6개월 직접 계약) + release clause 활성화 |
| **CpuTransferAi** | **AI 구단 능동 영입** — 약점 라인 / 부상자 대체 / FA 임박 / 약속 미이행 / 자금 여유 5 트리거 (매주 월요일) |
| **ScoutingSystem** | **명단 시스템** — 자기 구단 자동 / 외부는 Scout 시설 등급 기반 무작위 확장 + 매주 +5 누적 / `lastUpdated` + 정확도 margin |
| **ScoutingVisibility** | 가시성 헬퍼 — Scouted = 정확 수치 / Not Scouted = 5단계 정성적 라벨 (VeryHigh / High / Average / Low / VeryLow) |
| **FacilitySystem** | **8종** (Scout / Training / YouthCoach / YouthRecruitment / YouthFacility / Medical / Stadium / Gym) × **10단계** + 병렬 업그레이드 |
| **GrowthSystem** | 신규 — 매월 1일 + 2단계 모델 (발생 확률 + size 추첨 +1/+2/+3) + Training/Gym 시설 / Absolute vs Relative 메타 |
| **InjurySystem** | 신규 — 매치 중 부상 발생 (`injuryProneness` 비례) + 회복 일수 (Medical/Gym 시설) + ProcessRecovery 일일 호출 |
| **MoraleSystem** | 신규 — Tick (일일 사기 50 수렴 + professionalism 보정) + OnMatchFinished / OnTransferCompleted / OnContractRenewed / OnPromiseFulfilled/Broken / OnInterview + Hidden 보정 (professionalism ±30% / loyalty 충격 완화) + 라커룸 분위기 (월별 갱신) |
| **PromiseSystem** | 신규 — 4종 약속 (PlaytimeAgreement / TransferIn / Renewal / TransferOut) + `CheckProgress` 매주 + Promise Created/Fulfilled/Broken/DeadlineApproaching 이벤트 |
| **MentoringSystem** | 신규 — 매월 1일 Mentor → Mentee Hidden Attrs (professionalism / ambition / loyalty) 수렴 |
| **CaptainSystem** | 신규 — 자동 배정 (`leadership + min(age,35)×0.5 + yearsLeft×2`) + 수동 변경 |
| **TacticImpact** | 신규 — Role × Duty × Stat 이벤트 주체 가중 추첨 (MatchSimulator.SnapPlayer 통합) |
| **SubstitutionAI** | 신규 — fatigue 임계 / 부상 / 스코어 상황 기반 자동 교체 |
| **SetPieceResolver** | 신규 — Corner / FreeKick / Penalty / LongThrow 4종 (지정 키커 우선) |
| **SeasonAwardSystem** | 신규 — 시즌 어워드 7종 (LeagueMVP / TopScorer / TopAssist / YoungPlayer / BestEleven / GoldenGlove / ManagerOfSeason) + 월간 어워드 (Player/Manager of Month) |
| **BoardSystem** | 신규 — 매월 평가 (목표-실제 순위) + 매치 평가 + boardConfidence < 30 = 경고 / < 10 = 경질 (Game Over) + boardPromises (시즌 시작) |
| **FinanceSystem** | 신규 — 시즌 결산 (입장료 + TV 중계권 + 상금 차등) + Match 데이터 압축 |
| **ManagerReputationSystem** | 신규 — 우승 / 경질 / 월간 매니저 트리거 + boardConfidence 가산 |
| **SeasonEndProcessor / NewSeasonProcessor** | V0.1 FA 전환 + 은퇴 + 토큰 +3 + fatigue 리셋 + 새 일정 + **시즌 시상 + 보드 약속 + 재정 결산 + Match 압축 + 매니저 평판** |

### 1.3 UI 화면 (V0.1 11개 + V0.5 7개 = **18개 씬**)
- **MainMenu / ClubSelect / Gacha** — V0.1 그대로
- **Dashboard** — 인박스 (Promise / Board / 매치 / TransferRequest / YouthPromotion) + 다음 매치 상세 + 사기/부상 요약 + 사이드 메뉴 확장 (Lineup / Mentoring 추가) + [저장] + [메인 메뉴]
- **Squad / PlayerProfile** — 자기 구단 정확 stats 수치 노출 (V0.1 5단계 티어 폐기) + 시즌별 커리어 + 캡틴/부캡틴 배지 + Mentoring 그룹 표시
- **Youth** — V0.1 인스펙션 그대로 + 풀 전체 영입 옵션
- **Transfer** — 검색 필터 확장 (포지션 / CA 범위 / 연령 / 국적 / 트레잇 / 시장가 / 계약 잔여) + 가시성 분기 (Scouted = 정확 / Not Scouted = 정성적 라벨)
- **Schedule / Standings / Facility** — V0.1 그대로 + Facility 8 시설 × 10단계 표시
- **TacticScene** — Formation 선택 + 11 슬롯 Role / Duty 편집 + Mentality 7단계 (신규)
- **LineupScene** — 11 슬롯 선수 배정 (Player 드롭다운) + Set Pieces 4종 키커 지정 + 자동 배정 (신규)
- **MatchTextScene** — Match.events 분 단위 표시 (신규, 미완)
- **MentoringScene** — Mentor / Mentee 그룹 관리 (신규, 동작 불안정 — §2 참조)
- **NegotiationScene** — CounterOffer 응답 (Accept / Reject / ReCounter) + 협상 라운드 표시 (신규)
- **PromiseInboxScene** — active promises 목록 (신규, 진행률 표시 미완)
- **SeasonSummaryScene** — 시즌 시상 + 보드 평가 + 재정 결산 + 다음 시즌 목표 (5/15 자동 진입)

### 1.4 도메인 / 인프라 확장

## 3. 플레이에 필요한 정보

### 3.1 시작하기
1. 메인 메뉴 → **New Game**
2. 시드 입력 (선택) — 같은 시드 = 같은 초기 스쿼드.
3. 구단 선택 — 명성 내림차순.
4. 스타팅 가챠 — 4라인 티어 + [리롤] (최대 3회) + 포메이션도 랜덤화됨. [확정] → Dashboard.
5. **Continue** 를 누르며 시즌 진행. 사기 / 부상 / 약속 알림이 Dashboard 인박스에 누적.

### 3.2 V0.5 신규 메커닉

| 메커닉 | 사용법 |
| --- | --- |
| **사기 / 행복도** | 매치 결과 / 출전 시간 / 재계약 / 약속 이행 기반 변동. Squad / PlayerProfile 에서 확인. Happiness < 20 → TransferRequest 자동 발행 |
| **약속 (Promise)** | 면담 / Dashboard 인박스에서 4종 약속 생성 가능 (PlaytimeAgreement / Renewal / TransferIn / TransferOut). 미이행 = Happiness 페널티 |
| **면담** | PlayerProfile 의 [면담] 버튼 — 4 멘트 선택지 (출전시간 약속 / 새 계약 / 칭찬 / 질책). loyalty / ambition / professionalism 에 따라 효과 다름 |
| **스카우트 명단** | Transfer 검색 시 자기 구단 스카우트 시설 등급 + 시간 누적에 따라 정확도 다름. **Scouted** 선수 = 정확 수치 / **Not Scouted** 선수 = 5단계 정성적 라벨 ("매우 높음" / "높음" / "중간" / "낮음" / "매우 낮음") |
| **CounterOffer 협상** | 오퍼 제출 후 며칠 → AI 응답 (CounterOffer 또는 Rejected). Dashboard 자동 NegotiationScene 라우팅 → [수락] / [거절] / [재역제안] |
| **임대 (Loan)** | TransferController 의 isLoan 토글 → loanFee + 종료일 지정. loanEndDate 도래 시 자동 원 구단 복귀 |
| **상시 재계약** | PlayerProfile 의 [재계약] 버튼 — 잔여 기간 무관. 주급 ↑ → 사기 회복 + 충성도 가산 |
| **시설 8종 × 10단계** | Facility 화면. Scout / Training / YouthCoach / YouthRecruitment / YouthFacility / Medical / Stadium / Gym. 동시 N개 업그레이드 가능 |
| **유스 1군 콜업** | 18세 + CA ≥ 클럽 평균 ×0.70 → Dashboard 인박스 자동 알림 → PlayerProfile [1군 승격] |
| **Mentoring** | (UI 불안정) 베테랑 → 어린 선수에게 Hidden Attrs (professionalism / ambition / loyalty) 수렴. 매월 1일 처리 |
| **Tactic** | TacticScene 에서 Formation (6종) + 11 슬롯 Role (40종) / Duty (A/S/D) + Mentality (7단계) + Set Pieces 4종 |
| **시즌 종료** | 5/15 도래 → SeasonSummaryScene 자동 진입 — 시상 / 보드 평가 / 재정 결산 / 다음 시즌 목표. boardConfidence < 10 = Game Over |
