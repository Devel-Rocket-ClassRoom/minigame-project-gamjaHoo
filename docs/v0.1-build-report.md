### 주요 (P1)
- **#170 — 이적 제안 디폴트 입력값이 시장가 → AI 무조건 Reject** ✅ **fix 머지됨 (PR #171)**
  - 원인: `TransferController.ShowOfferPanel` 가 `offerAmountInput.text = mv.ToString()` 으로 시장가 그대로 디폴트. AI Accept 조건 ratio ≥ 1.20 (`design-decisions.md` #37) 과 불일치.
  - 수정: 디폴트값을 시장가 ×1.30 으로 변경. 사용자가 흥정 원하면 직접 줄임.
- **#172 — 유스 인스펙션 후보 토글 클릭 안 됨** ✅ **fix 머지됨**
  - 원인: `YouthCandidateItem.prefab` 의 Toggle Target Graphic Image 두 개의 `m_RaycastTarget = 0` (raycast 비활성) → 클릭 영역에서 raycast 가 잡히지 않아 토글 이벤트 발화 X.
  - 수정: 두 Image 의 `Raycast Target = true` 활성화 + RectTransform anchor (`0.5,0.5 → 0,0`) / SizeDelta 명시 / Vertical Layout Group `ChildControlWidth/Height = 0` 정돈.
  - 코드 변경 없음 — 프리팹 인스펙터 설정만.
