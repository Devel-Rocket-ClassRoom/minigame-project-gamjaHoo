## 1. V0.5 → V0.6 핵심 변화

V0.5 가 "스코어 + 사기 + 이적 + 시설 + 시즌 사이클이 돈다" 였다면, V0.6 은 거기에 **(1) 일관된 글로벌 UI, (2) FM 식 인박스 자유도, (3) 정밀화된 매치 엔진(xG), (4) 통합 전술·라인업, (5) 시각화된 스탯** 을 얹었다.

1. **글로벌 네비게이션 (GlobalNav)** — 씬이 바뀌어도 TopBar(날짜/자금/토큰/인박스/옵션/저장/홈) + SideBar(메인 메뉴) 가 고정 위치. V0.5 의 "씬마다 버튼 위치가 다르다" 피드백 해결.
2. **인박스 자유도** — 이벤트 발생 시 강제 씬 전환 폐기. FM 식 피드로 알림만 쌓이고 사용자가 클릭해 처리. 기한 있는 항목(보드 약속)만 모달 잠금.
3. **xG 찬스-퀄리티 매치 엔진** — V0.5 의 블런트한 5-zone 골 산정 → 찬스별 xG 모델 + 골 빈도 2.7±0.3 수렴 + **평점 시스템 FM 정합 재설계**.
4. **Tactic ↔ Lineup 통합 씬** — V0.5 의 분리된 두 씬 + dropdown 가림 문제 → **TacticLineupScene** 단일 씬 (피치 도식 + 드래그 배정 + Role/Duty 팝업) + **MatchPreviewScene** 매치 전 점검.
5. **Player stat UI 재설계** — 49 stat 한 화면 + 색상 코딩(80/65/50/35) + 신체 조건 + 성장 동향 화살표.
6. **Options / 통화 / 자동 저장** — 사운드 슬라이더(silent) / 언어 / 통화(£/$/€/₩) / UI Scale / 자동 저장 토글.

### 2.3 UX 패러다임 — 인박스 자유도 (Stage B)
- **인박스 패널** — TopBar [인박스] 클릭 시 우측 슬라이드 (어디서든 동일). 카테고리 탭 (전체 + Match/Transfer/Morale/Board/Youth/Cup/Award) + 안 읽음 강조 + 카테고리 색 스트라이프 + 기한 D-N/만료
- **강제 씬 전환 폐기** — CounterOffer 도착 / YouthIntake / YouthPromotion 시 자동 씬 전환 → InboxItem 알림으로 변환. Continue 가 더 이상 멋대로 씬을 바꾸지 않음
- **기한 항목만 모달 잠금** — 보드 약속(시즌 시작 미응답)은 모달 유지. 매치 시작은 MatchPreviewScene 정지(Q6)
- **인박스 정책 (Q1+Q2)** — 기한 도래 시 자동 처리 X (흐리게 비활성), 시즌 종료 시 읽은 항목만 삭제

### 2.4 Player Profile + Squad 시각화 (Stage C / D)
- **한 화면 49 stat (C.1)** — FM 식 풀-높이 컬럼 (outfield 3컬럼 / GK 4컬럼), 스크롤 없음, 1920×1080 fit
- **stat 색상 코딩 (C.2)** — 80+ Elite(녹) / 65-79 Good / 50-64 Average(회) / 35-49 Weak(주황) / -34 Poor(빨강). Hidden 동일 적용

- **성장 동향 화살표 (C.4 / D.2)** — 직전 3개월 stat·CA 변화량 → 진녹↑ / 녹↗ / 회→ / 주황↘ / 빨강↓
- **Squad 검색 폐지 (D.1)** — 스쿼드 내 검색 불필요 → 제거 + 프로필 뒤로가기 씬 캐싱(`PreviousScene`)

### 2.7 Match Simulation 정밀화 (Stage G)
- **xG 찬스-퀄리티 레이어 (G.5)** — chanceType별 baseXG → 골 = xG × finishMod × gkMod. 팀당 ΣxG≈1.35 → 경기 평균 2.76골 / std 1.62 (Poisson 정합)
- **평점 시스템 전면 재설계 (G.5, #70)** — 포지션 가중 + 패스 성공률 + DF 무실점 공유 + xG 보정(clinical/빅찬스 미스). FM 정합
- **이벤트 종류 확장 (G.1)** — 패스 / 턴오버 / 스로인 / 프리킥 / 오프사이드 / GK 펀칭
- **신체·멘탈리티 반영 (G.2)** — 헤더(키×점프+jumpingReach) / agility(키 작을수록↑) / pace+weakFoot / PK·FK 발 일치 보너스
- **선수 조합 시너지 (G.3)** — `SynergySO` 10 카탈로그 + `TacticImpact.ComputeSynergies` + xG 비율 적용
- **전술 상성 (G.4)** — `FormationMatchupSO` 6×6=36 매트릭스 + teamMod 합산
- **매치 텍스트 변형 (G.6)** — 시드 기반 변형 선택 (같은 시드 = 동일 표현 시퀀스, gameplay rng 미소비)

## 4. 플레이에 필요한 정보

### 4.1 시작하기
1. 메인 메뉴 → **New Game** → 시드 입력(선택) → 구단 선택(명성 내림차순) → 스타팅 가챠 → [확정]
2. **TopBar / SideBar (GlobalNav)** 가 모든 씬에서 고정. 날짜/자금/토큰/인박스 배지가 항상 보임
3. **Continue** 로 진행 — 알림은 **TopBar [인박스]** 에 쌓임 (강제 씬 전환 없음, 보드 약속만 모달)
4. 매치일 → **MatchPreviewScene** 자동 정지 → 라인업/전술/시너지 점검 → [매치 시작]
