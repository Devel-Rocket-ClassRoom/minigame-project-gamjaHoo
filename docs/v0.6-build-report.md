## 7. 종합 결론

### 의도대로 잘 동작한 부분
1. **글로벌 네비 + 인박스 자유도** — V0.5 의 핵심 피드백("씬마다 버튼 위치 다름", "강제 씬 전환")을 정면 해결. 씬별 인스턴스 모델로 모든 컨텐츠 씬 일관 UI.
2. **xG 매치 엔진 + 평점 재설계** — 블런트 튜닝 폐기 → 찬스-퀄리티 레이어. 골 빈도 2.76(목표 2.7±0.3) + FM 정합 평점.
3. **Tactic ↔ Lineup 통합 + 매치 프리뷰** — V0.5 의 분리 씬 + dropdown 가림 문제 해소. 피치 도식 드래그 + Role/Duty 팝업 + 매치 전 점검.
4. **Player stat 시각화** — 49 stat 한 화면 + 색상 코딩 + 신체 조건 + 성장 화살표.

### 추가 정정 / 다듬기 필요한 부분
1. **LocalizationData.asset 재생성** (빌드 전 필수).
2. **Stage R 잔여 밸런싱** (재정 / 명성 / 인박스 확장) — 플레이 체감 직결.
3. **Stage S 잔여 폴리싱** + 미구현 Stage (사운드/컵/매치결과 대시보드/훈련).

### 빌드 비전 단어
- V0.1: "스코어가 나온다."
- V0.5: "스코어 + 사기 + 이적 + 시설 + 시즌 사이클이 돈다."
- **V0.6: "UI 가 일관되고(GlobalNav/인박스), 매치가 자세하다(xG/평점/통합 전술)." — V1.0 의 절반.**
- V1.0 (목표): "UX 가 매끄럽고, 매치가 자세하고, 시장이 정교하다 (컵 / 훈련 / 매치결과 대시보드 / 밸런싱 완성)."
