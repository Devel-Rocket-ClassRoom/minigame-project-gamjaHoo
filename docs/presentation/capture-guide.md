# FM-Lite 발표자료 — 스크린샷 캡처 가이드

> ✅ **현재 상태(2026-06-07):** `assets/` 의 스크린샷 8장이 발표자료에 **이미 임베드**되어 있다.
> 더 좋은 컷으로 교체하려면 같은 파일명으로 덮어쓴 뒤 `python docs/presentation/build_pptx.py` 재실행만 하면 된다.
> 아래 표는 어떤 화면이 어느 슬라이드에 쓰였는지에 대한 매핑이다.

발표자료(`FM-Lite_발표자료.pptx`)에는 **스크린샷 자리(점선 박스 📷)** 가 들어 있다.
아래 목록대로 캡처해서 해당 슬라이드의 점선 박스 위에 끌어다 놓으면 된다.
(박스를 지우고 이미지를 넣거나, 이미지를 위에 덮어도 됨. 권장 비율 = **거의 정사각형, 4:4~4:5**.)

> **권장 캡처 방법:** Unity 게임 뷰를 **1920×1080** 또는 그 비율로 띄우고 `Win + Shift + S`(영역 캡처).
> UI 가 1920×1080 기준으로 맞춰져 있으므로 풀 해상도 캡처가 가장 깔끔하다.

---

## 필수 (점선 박스가 이미 있는 슬라이드)

| 슬라이드 | 화면 | 무엇이 보이게 |
|---|---|---|
| **4. 게임 소개** | **메인 대시보드** | 다음 경기 카드 · 일정 · 인박스 알림이 한 화면에 모인 메인 허브 모습 |
| **11. 매치 엔진 개요** | **매치 텍스트 씬** | 텍스트 이벤트가 흐르는 중간 장면 + 가속 버튼(1/2/3/4) + 양 팀 라인업/스코어 |

## 권장 추가 (있으면 발표가 풍부해짐 — 원하면 해당 슬라이드에 직접 추가)

| 넣을 슬라이드 | 화면 | 포인트 |
|---|---|---|
| 1. 타이틀 | 메인 메뉴 / 클럽 선택 | 게임의 첫인상(크레스트·다크 UI). 우측 빈 공간에 작게 |
| 5. 구현 범위 | 스쿼드 + 전술 도식 콜라주 | 포메이션 피치에 선수 배치된 모습 |
| 12. xG 레이어 | 매치 결과 — 슛맵/히트맵 대시보드 | xG·슛맵 데이터가 실제로 시각화된 증거 |
| 13. 평점 재설계 | 매치 결과 선수 평점 리스트 | 포지션별로 평점이 갈리는 표 |
| 14. 정보 비대칭 | 선수 프로필 (스탯 색상 코딩) | 49 stat 컬러 등급 + 미정찰 trait 가려진 모습 |
| 15. AI 협업 | GitHub Projects 보드 / PR 목록 | 이슈→PR→머지 흐름의 실제 캡처 |

## 캡처 후 한 번에 자동 삽입하고 싶다면

스크린샷 파일명을 아래처럼 맞춰 `docs/presentation/assets/` 에 넣고 알려주면,
빌드 스크립트가 점선 박스 자리에 자동으로 끼워 넣도록 갱신해 줄 수 있다.

```
docs/presentation/assets/
├─ 04_dashboard.png        # 필수
├─ 11_match_text.png       # 필수
├─ 01_main_menu.png        # 선택
├─ 05_squad_tactic.png     # 선택
├─ 12_shotmap.png          # 선택
├─ 13_ratings.png          # 선택
├─ 14_player_profile.png   # 선택
└─ 15_github_board.png     # 선택
```

그러면 `python docs/presentation/build_pptx.py` 재실행만으로 이미지가 박힌 최종본이 나온다.

---

## 빠른 재생성

내용·문구를 고친 뒤에는:

```powershell
python docs/presentation/build_pptx.py
```

→ `docs/presentation/FM-Lite_발표자료.pptx` 가 덮어쓰기로 다시 생성된다.
