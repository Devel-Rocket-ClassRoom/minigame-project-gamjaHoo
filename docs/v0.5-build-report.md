## 5. 발견된 이슈 / 버그

> 심각도: `P0` (블로커) / `P1` (주요) / `P2` (사소).

### 5.1 본 빌드 중 hotfix 머지된 항목

- **#384 — 이적 흐름 (AI 응답 타이밍 + Back 버튼)** ✅ **fix 머지됨 (PR #385)**
  - **증상 1:** AI 응답이 시즌 종료에만 surface — 시즌 중간에 오퍼 제출 후 며칠 후 AI 응답이 도착하지만 Continue 가 정지하지 않아 다음 매치/시즌 종료까지 묻혔음.
  - **원인:** `EventScheduler.Run` 이 user 매치/유스/시즌만 stopRequested 발화. CounterOffer/Rejected 도착에 대해 정지 신호 X. OnContinueClicked 의 CounterOffer 체크는 우선순위 3번이라 매치/시즌에 가려짐.
  - **수정:** `TransferOffer.lastResponseDate: DateTime?` 신규 + `AiRespondToOffer` 가 설정 + `EventScheduler.TryTriggerOfferResponded` 신규.
  - **증상 2:** NegotiationScene [뒤로] 클릭 → 씬 전환 X (그 씬에 갇힘).
  - **원인:** `OnBackClicked()` 메서드는 코드에 존재. NegotiationScene 의 [뒤로] 버튼 `m_OnClick` 에 컨트롤러 메서드 wire 누락.
  - **수정:** NegotiationScene.unity 의 [뒤로] 버튼 `m_OnClick` → `FMLite.UI.NegotiationController.OnBackClicked` 연결.
